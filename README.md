# SysGuardian

SysGuardian é uma ferramenta profissional de diagnóstico e auditoria para servidores Linux.

## Recursos

- Diagnóstico completo do sistema
- CPU
- Memória
- Discos
- SMART
- Rede
- Segurança
- Apache
- PHP
- MySQL
- Docker
- Backup
- Relatórios TXT
- Relatórios HTML
- Relatórios PDF

Compatível com Ubuntu 22.04 e 24.04 LTS.
